# Rahim Iqbal — Portfolio

Personal portfolio site for Rahim Iqbal (ML Engineer / Full-Stack Developer, University of Moratuwa).

Built with React 19, TypeScript, Vite, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages automatically. To enable it on a new repo, turn on **Pages → Build and deployment → GitHub Actions** in the repo settings.
